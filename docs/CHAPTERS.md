# 居酒屋、喫茶店同暗黑食堂

完成第一更後，喺收工頁揀「返大堂／揀章節」。舊玩家亦可以喺大堂直接切換。四章共用金幣、經驗、食譜星級同單詞溫習；原有四款食譜解鎖條件保留，各章有獨立餐牌。

居酒屋：枝豆、焼鳥、唐揚、揚出豆腐、大阪燒、日式炒麵。客人會追加一份，收入按新份數計；亦會遇到沽清，要聽清楚客人改要邊道菜。冇加入飯糰。

喫茶店：精品即溶咖啡、紅茶、抹茶拿鐵、雞蛋布甸、牛油厚多士、熱香餅。三個固定客人外形配搭讀書、散步、畫畫常客身份；飲品單會要求熱飲、凍飲、少甜。玩家先理解要求，再喺製作最後一步揀啱調整。凍飲成品有冰粒；完成製作先增加到訪紀錄。

新餐飲都有程式繪製嘅 3D 成品；新材料亦有細模型。新詞彙介面用有文字標籤嘅食物圖示，未新增專屬手繪點陣素材。新對白沿用現有瀏覽器日文語音後備機制，未新增預錄音檔。付費、分單、新店舖建築同熟客長篇故事不包括喺呢個版本。

暗黑食堂「主廚，叮好喇！」包括七款：01 叮叮大餐、02 三分鐘燉牛肉、07 瓶裝奶綠、08 暗黑即溶咖啡、09 鮮果梳打、26 一秒老火湯、25 味精核爆炒飯。流程係點餐、揀真正材料、快捷製作、揀餐具／裝飾／菜名、上菜，再揭曉秘密卡。倒數係縮時遊戲演出，食譜寫明實際翻熱跟包裝。

好味按小遊戲表現計；炒飯調味步驟權重 3，最佳調味 2 格，過量會扣分。賣相按餐具及裝飾計；宣傳誇張度獨立顯示，唔加金幣或星級。擺盤會添加 3D 餐具／裝飾，微波爐會發光。秘密卡記錄最新結果、最好口味及製作次數，後廚圖鑑解鎖七類捷徑；未解鎖只顯示鎖卡。無真實分享／社交服務整合。

存檔沿用 `catcook_v1`，增加 `chapter`、`chapterShifts`、`regularVisits`、`darkSecrets` 預設值，唔會重置舊進度。四章目前均毋須付費。

驗證：

- `python scripts/check-chapters.py`：兩章各六款、全部食譜詞彙／模型、三種手機尺寸切換章節、真實揀材料／控火操作；隔離料理小遊戲後檢查五次出餐流程、加單／沽清、三種熟客要求、獎勵及存檔重新載入。流程測試取代小遊戲評分，唔代表每款菜嘅全部手勢都獨立重測。
- `python scripts/check-dark.py`：七款暗黑料理、四章手機切換、真實微波爐／調味操作、九次隔離料理手勢後嘅出餐流程；包括七張秘密卡、調味過量扣分、誇張菜名冇收入加成同存檔重新載入。
- `python scripts/check-window-recipe.py`：二十三款食譜、四個尺寸，開始按鈕毋須捲到底；窗景分層。
- `python scripts/check-mobile.py`：既有二十一組鏡頭／泡泡邊界及圖鑑載圖檢查。
