# 居酒屋同喫茶店：首版

完成第一更後，喺收工頁揀「返大堂／揀章節」。舊玩家亦可以喺大堂直接切換。三章共用金幣、經驗、食譜星級同單詞溫習；原有四款食譜解鎖條件保留，新章六款菜各自成為獨立餐牌。

居酒屋：枝豆、焼鳥、唐揚、揚出豆腐、大阪燒、日式炒麵。客人會追加一份，收入按新份數計；亦會遇到沽清，要聽清楚客人改要邊道菜。冇加入飯糰。

喫茶店：精品即溶咖啡、紅茶、抹茶拿鐵、雞蛋布甸、牛油厚多士、熱香餅。三個固定客人外形配搭讀書、散步、畫畫常客身份；飲品單會要求熱飲、凍飲、少甜。玩家先理解要求，再喺製作最後一步揀啱調整。凍飲成品有冰粒；完成製作先增加到訪紀錄。

十二款新餐飲都有程式繪製嘅 3D 成品；新材料亦有細模型。新詞彙介面用有文字標籤嘅食物圖示，未新增專屬手繪點陣素材。新對白沿用現有瀏覽器日文語音後備機制，未新增預錄音檔。暗黑食堂、付費、分單、新店舖建築同熟客長篇故事不包括喺呢個版本。

存檔沿用 `catcook_v1`，只增加 `chapter`、`chapterShifts`、`regularVisits` 預設值，唔會重置舊進度。三章目前均毋須付費。

驗證：

- `python scripts/check-chapters.py`：兩章各六款、全部食譜詞彙／模型、三種手機尺寸切換章節、真實揀材料／控火操作；隔離料理小遊戲後檢查五次出餐流程、加單／沽清、三種熟客要求、獎勵及存檔重新載入。流程測試取代小遊戲評分，唔代表每款菜嘅全部手勢都獨立重測。
- `python scripts/check-window-recipe.py`：十六款食譜、四個尺寸，開始按鈕毋須捲到底；窗景分層。
- `python scripts/check-mobile.py`：既有二十一組鏡頭／泡泡邊界及圖鑑載圖檢查。
- `npm run build`：GitHub Pages 相對路徑正式版本。

以上使用 Chromium 模擬，未用實體手機驗證。
