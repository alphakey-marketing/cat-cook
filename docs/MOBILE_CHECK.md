# 手機版修正驗證

原本 390×844 畫面，客人泡泡右邊約 454px，超出螢幕。原因係泡泡以角色投影座標置中，冇按自身闊度限制邊界；窄屏鏡頭亦未能容納客人全身。

修正包括：按比例拉後鏡頭；按 HUD、底部面板同畫面邊界限制泡泡位置；長對白換行／捲動；移除泡泡時取消 3D 追蹤；手機網格、食譜同圖鑑文字允許收窄及換行。

`python scripts/check-mobile.py` 使用 Chromium，檢查 320×568、375×667、390×844、430×932、768×1024、844×390 同 1280×800，分別驗證廚房、上菜及煮食鏡頭，共 21 組。檢查長對白邊界、客人模型八角投影、頁面冇水平溢出、商店／圖鑑／設定／食譜載圖、全部單詞素材及泡泡清理。

畫面截圖見 `docs/art-review/mobile-*.png`。呢啲係瀏覽器模擬尺寸檢查，未使用實體手機。
