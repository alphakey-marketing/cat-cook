## 0. 先講等級：而家有 3 級，你想要 4 級

| 遊戲內部 `jpLevel` | 而家 | 你想要 | 改動 |
|---|---|---|---|
| 0 🌱 | 零基礎 | 零基礎 | 不變 |
| 1 🌿 | 初學（N5–N4） | **N5** | 名稱改做 N5，N4 句子順延到 N3 邊界（見下面問題 1） |
| 2 🌳 | N3 或以上 | **N3** | 上限收返去 N3 |
| 3 🏔️ | **冇** | **N1** | 新增 |

**真相：而家冇 N1。** `phrases.js` 入面 `jpLevel` 係 `Math.max(0, Math.min(2, …))`，最高 2。加 N1 要改：

1. `LEVELS` 加第 4 項，`jpLevel` 上限改 3。
2. 設定畫面「日文程度」加一粒掣。
3. 升級提示 `lvStats`（答夠 10 題 80%）自動兼容，只要加多一級。
4. 新句只用 `usagi／kuma` 兩把聲線（跟現有慳音檔規則），所以音檔量唔會爆。
5. 舊存檔 `jpLevel` 0–2 唔受影響。

### 要你決定嘅問題

1. **N4 放邊？** 而家「初學」包 N5–N4。你話要 N5 → N3 → N1，中間 N4 冇位。建議：N4 句子歸入 N3 級（因為 N3 本身「想練聽力同實用句子」），N5 級淨係出 N5 程度句型。
2. **玩家角色**：酒店／車站邊個做主角？
   - 建議：**你係遊客**（買票、check-in）。N1 級加少量「聽廣播／聽店員長句」。
   - 備選：做前台（同便利店收銀同款玩法），但對旅行幫助較細。
3. **車站廣播**：用唔同聲線／加雜音？建議用 `cat` 或 `kuma` 配「車站廣播」濾鏡，之後先研究。

### 酒店流程（`hotelServe`）
1. 入門（いらっしゃいませ）→ check-in（按等級）→ 前台報房號 → 揀返房號。
2. 住宿中：抽一個請求（毛巾、寄存、早餐、Wi-Fi、冷氣、換房、帳單、加住）。
3. 退房（收據、信用卡結帳等）。
資料：`src/data/hotel.js`（CHECKIN、ROOM_REPLY、REQUESTS、CHECKOUT、STAFF_RUDE_H、HOTEL_WORDS）。

### 改句子嘅方法
- 句子寫成 `漢字{かな}`；佔位符 `{p}` 人數、`{q}` 另一個人數、`{n}` 晚數、`{f}` 樓層、`{r}` 房號（`{py}` `{nn}` `{fn}` `{rn}` 係廣東話版）。
- 新增句子後要跑 `npm run voice`（需要 VOICEVOX）先有音檔，否則用瀏覽器 TTS。
